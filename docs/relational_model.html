🚀 Alur Bisnis Sistem Quotation

📦 Client (company + contact person) minta barang
➔
📝 Operasional buat Quotation + item dari histori — harga otomatis kena diskon 5%
➔
📤 Quotation dikirim ke client
➔
💬 Client setuju?
❌ Reject ➔ Buat revision (versi baru, data lama tetap tersimpan)
✅ Setuju ➔ Client kirim PO ➔ Upload PO ke sistem ➔ Verifikasi PO vs Quotation ➔ Buat Invoice ➔ Export Coretax

Penomoran:   Quotation: Q-{YY}{kode_client}{seq}/GNS/{Bulan Roman}/{YYYY}  |  PO: PO-...  |  Invoice: INV-...  — contoh: Q-264128/GNS/IV/2026

Pricing flow: Total → Diskon 5% (product saja, hardcoded) → Sub Total → DPP Nilai Lain (×11/12) → PPN 12% (fixed) → Grand Total = DPP Nilai Lain + PPN

14 tabel: 7 Master Data (biru) + 4 Transaction (amber) + 2 Finance (hijau) + 1 System (ungu)

Keterangan kolom: AUTO  Diisi otomatis oleh sistem (id, timestamps) | GENERATED  Dihitung otomatis dari kolom lain (DB computed) | FK  Referensi ke tabel lain | Tanpa badge = diisi manual oleh user

🏢 company_client

Master Data

Data perusahaan pelanggan (level korporat). Menyimpan info pajak (NPWP, TKU) untuk Coretax. Satu perusahaan bisa memiliki banyak contact person (company_contacts) dan banyak quotation. number adalah kode singkat perusahaan (2 digit) yang digunakan dalam penomoran quotation. Contoh: kode "41" → quotation no. Q-264128/GNS/IV/2026 (26=tahun, 41=kode, 28=seq).

📝 quotation_items

Transaction

TABEL TERPENTING. Setiap baris item dalam quotation memiliki dua sisi:
1. REQUEST (dari dokumen client) — disimpan verbatim di requested_impa + requested_name. Jika request matches ke item master, requested_item_id diisi; jika tidak (item baru/tidak dikenal), tetap NULL tapi requested_name wajib diisi.
2. OFFER (yang kita tawarkan) — mengacu ke offered_item_id (master items kita) + vendor_product_id (sumber pembelian).
Diskon otomatis 5% untuk item_type = 'product'. Shipping tidak kena diskon. Generated columns menghitung profit dan subtotal per baris. UNIQUE pada (quotation_id, line_number).
Jika client tidak bisa dipenuhi, set is_available = false dan selling_price = 0 ("No Offer").
