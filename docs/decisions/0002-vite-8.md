# ADR 0002 — Vite 8 with Rolldown and plugin-react

Date: 2026-09-26
Status: Accepted

## Context

- Vite 8 replaces Rollup and esbuild with Rolldown and Oxc. The object form
  of `output.manualChunks`, which split `tanstack-vendor`, is no longer
  supported, and `build.rollupOptions` is now `build.rolldownOptions`.
- Lightning CSS is the default CSS minifier.
- The default browser target rises to Chrome 111, Edge 111, Firefox 114 and
  Safari 16.4 (from 107, 107, 104 and 16.0).
- On Vite 8, `@vitejs/plugin-react-swc` warns that it adds nothing when no
  SWC plugins are configured, and recommends `@vitejs/plugin-react`. None
  are configured here.

## Decision

- Move to `vite` ^8.3.1 and `@vitejs/plugin-react` ^6.1.1 (Oxc React
  Refresh, peer `vite ^8`), and drop `@vitejs/plugin-react-swc`.
- Keep the `tanstack-vendor` chunk through one Rolldown `codeSplitting`
  group matching `react`, `react-dom`, `@tanstack/react-query` and
  `@tanstack/react-router`. Groups include their dependencies recursively by
  default, as the object form did, so the chunk keeps the same libraries.
- Keep Lightning CSS and the new default target. No `build.target`,
  `build.cssTarget` or browserslist is set; the bundler default governs.
- Resolve config paths with `import.meta.dirname` instead of `__dirname`,
  which the planned native config loader will not provide.

## Consequences

- **+** Build time drops from about 5.3 s to under 1 s. JS gzip drops from
  542 kB to 525 kB in total, and the JS loaded by `index.html` drops from
  118.0 kB to 115.7 kB gzip. `tanstack-vendor` drops from 337.8 kB to
  325.5 kB raw.
- **+** `index.html` now loads five JS files instead of two, including a
  1 kB `rolldown-runtime`. The byte total is still lower.
- **−** Browsers below the new target lose support. The CSS uses range media
  queries (`@media (width>=40rem)`) and `oklab()` colour fallbacks, so Safari
  16.0 to 16.3 loses every responsive breakpoint. Accepted as the Vite 8
  baseline; pinning the targets restores the old output if a client needs it.
- **−** Lightning CSS output is 227 B larger. It leaves `calc()` unsimplified
  in custom properties and repeats `-webkit-text-decoration-color`. Both are
  harmless.

## Alternatives considered

- **`build.cssMinify: 'esbuild'`.** Rejected: esbuild is now only an
  optional peer, and the Lightning CSS output was reviewed as equivalent.
- **Pinning `build.target` and `build.cssTarget` to the Vite 7 defaults.**
  Not taken: nothing in the repo states a browser floor, so the bundler
  default applies. This is the escape hatch if a client below it turns up.
- **Dropping the vendor chunk.** Rejected: it keeps React and TanStack in a
  chunk whose hash survives app-only deploys, so browsers keep it cached.
