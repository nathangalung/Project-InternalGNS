# public.quotation_reconciliation

## Description

Reconciliation check: header total vs SUM items. Non-zero diff = inconsistency.

<details>
<summary><strong>Table Definition</strong></summary>

```sql
CREATE VIEW quotation_reconciliation AS (
 SELECT q.id,
    q.quotation_no,
    q.total AS header_total,
    COALESCE(sum(qi.total_selling), (0)::numeric) AS items_total,
    (q.total - COALESCE(sum(qi.total_selling), (0)::numeric)) AS diff,
    q.total_discount AS header_discount,
    COALESCE(sum(qi.discount_amount), (0)::numeric) AS items_discount
   FROM (quotations q
     LEFT JOIN quotation_items qi ON ((qi.quotation_id = q.id)))
  GROUP BY q.id, q.quotation_no, q.total, q.total_discount
)
```
